WINDIGO Overview
================

The Workflow Integrating Nuclear Data InvestiGations into Openmc (WINDIGO) is designed to assist 
prospective researchers and analysts with performing sensitivity and uncertainty analyses based on 
nuclear data inputs for OpenMC [1] models. WINDIGO's primary utility is two-fold: limit the need for users
to learn and construct inputs for tools such as SANDY [2] and FRENDY [3] as part of performing their desired
analyses, and provide post-processing functionality to alleviate script writing that would otherwise be required
for tasks such as generating sensitivity plots and calculating propagated uncertainties based on OpenMC
outputs.
